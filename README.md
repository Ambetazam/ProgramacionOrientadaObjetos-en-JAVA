## 📚 Sobre este repositorio

Este repositorio nace como un espacio personal de estudio para comprender, implementar y practicar los conceptos fundamentales de la **Programación Orientada a Objetos en Java**.

Los ejercicios se desarrollan siguiendo el material propuesto por el profesor **Francisco Blasco**, complementando cada ejercicio con experimentación propia, modificaciones y pequeñas pruebas destinadas a comprender mejor el funcionamiento del lenguaje y del paradigma orientado a objetos.

El objetivo no es únicamente resolver los ejercicios, sino **comprender por qué funcionan, cómo están estructurados y cuándo aplicar cada concepto**.

---

## 🎯 Objetivos

### Objetivo general

Desarrollar una comprensión sólida de la Programación Orientada a Objetos utilizando Java mediante la resolución progresiva de ejercicios y pequeños proyectos prácticos.

### Objetivos específicos

* Comprender la sintaxis fundamental de Java.
* Practicar variables, tipos de datos y operadores.
* Comprender estructuras de control.
* Diseñar y utilizar clases y objetos.
* Aplicar encapsulamiento.
* Comprender constructores y métodos.
* Practicar herencia.
* Comprender y aplicar polimorfismo.
* Utilizar abstracción e interfaces.
* Trabajar con excepciones.
* Utilizar colecciones y estructuras de datos.
* Comprender composición y agregación.
* Experimentar con archivos y persistencia.
* Integrar diferentes conceptos en pequeños proyectos.
* Desarrollar buenas prácticas de programación.

# 🧠 Metodología de estudio

Cada ejercicio seguirá, cuando sea posible, este proceso:

```text
┌──────────────────────┐
│ 1. Leer el problema  │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│ 2. Analizar requisitos│
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│ 3. Diseñar solución  │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│ 4. Implementar Java  │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│ 5. Ejecutar y probar │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│ 6. Experimentar      │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│ 7. Documentar        │
└──────────────────────┘
```

La intención es evitar convertir el repositorio en una simple colección de soluciones.

Cada ejercicio debe responder tres preguntas:

1. **¿Qué problema estoy resolviendo?**
2. **¿Qué concepto de Java/POO estoy practicando?**
3. **¿Por qué esta solución funciona?**

# 🔬 Filosofía del repositorio

Este repositorio sigue una idea sencilla:

> **No basta con hacer que el programa funcione. Hay que comprender por qué funciona.**

Por esta razón, algunos ejercicios pueden contener diferentes versiones de una solución.

Por ejemplo:

```text
solution-v1/
solution-v2/
solution-refactored/
```

La primera solución puede representar una implementación directa del problema, mientras que las siguientes pueden explorar mejoras relacionadas con diseño, legibilidad, reutilización o principios de POO.
